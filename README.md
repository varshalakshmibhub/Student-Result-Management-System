# 🎓 Student Result Management System

A Python and SQLite based Student Result Management System developed to efficiently manage student academic records.

## ✨ Features

- Add Student Records
- Update Student Information
- Delete Student Records
- Search Students
- View Student Results
- SQLite Database Integration

## 🛠️ Technologies Used

- Python
- SQLite
